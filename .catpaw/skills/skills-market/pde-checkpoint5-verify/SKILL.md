# PDE 第五关通关校验

## 概述

本 Skill 用于自动校验 PDE 闯关体系第五关的完成情况。第五关要求学员在【我的】tab页实现主题切换功能。

## 第五关通关标准

1. 点击底部【我的】tab，页面正常显示（不能白屏）
2. 【我的】页面中有主题切换功能（如主题颜色选择器）
3. 可将默认绿色主题切换到至少1个其它主题色
4. 切换后还能再切回绿色主题
5. 切换主题后回到【去哪跑】tab页，页面中的主要按钮、组件样式同步更新为对应主题色

## 常见不通过原因

1. 点击"我的"后白屏（路由/组件渲染问题）
2. "我的"页面没有主题切换功能
3. 切换主题后页面颜色没有实际变化

## 校验流程

### Step 1: 验证学员提供的 URL

学员需要提供他们的测试环境地址。正确格式为：

```
http://ulive-pde-explore-runmapfrontend-{mis号}.awp.sankuai.com/index.html
```

验证规则：
- 域名必须匹配 `ulive-pde-explore-runmapfrontend-*.awp.sankuai.com`
- 如果学员提供了 talos 地址（如 talos-better.sankuai.com）、或其他不匹配的链接，提示正确格式
- 如果缺少 `/index.html` 路径，自动补全
- 协议应为 http（该环境不支持 https）

如果 URL 不符合格式，回复：

> 你提供的链接格式不正确。第五关校验地址格式应该是：
> `http://ulive-pde-explore-runmapfrontend-你的mis号.awp.sankuai.com/index.html`
> 请提供正确的测试环境地址。

### Step 2: 访问首页确认基础功能正常

1. 使用浏览器导航到学员提供的 URL
2. 等待页面加载完成
3. 确认页面正常渲染（应该能看到"去哪跑"相关内容、底部导航栏等）
4. 确认底部有"去哪跑"、"开跑"、"我的"三个导航项

如果首页无法加载，告知学员检查部署状态。

### Step 3: 检查【我的】页面

1. 点击底部"我的"导航项（或直接导航到 `#/profile`）
2. 等待页面加载
3. 截图检查页面状态

**判断标准：**
- 如果页面白屏（DOM中几乎没有内容），判定不通过，原因：常见错误 #1
- 如果页面有内容但没有主题切换相关的UI（颜色选择器、主题选项等），判定不通过，原因：常见错误 #2

### Step 4: 测试主题切换功能

1. 在"我的"页面找到主题切换功能
2. 记录当前页面的主色调（截图）
3. 点击切换到另一个主题色
4. 截图对比，确认颜色确实发生了变化

**判断标准：**
- 如果切换后页面视觉没有变化，判定不通过，原因：常见错误 #3

### Step 5: 验证【去哪跑】页面样式联动

1. 切换到非绿色主题后，点击"去哪跑"tab
2. 截图检查页面中的按钮、组件颜色是否与新主题一致
3. 对比默认绿色主题时的样式，确认样式确实同步变化了

### Step 6: 验证切换回绿色主题

1. 回到"我的"页面
2. 切换回绿色主题
3. 确认能正常切回

## 重要提示

- 每一步都要截图留证，作为判断依据
- 判断要严格按照通关标准来，不能放水
- 如果页面加载慢，适当增加等待时间再判断
- 主题切换的实现方式不限（CSS变量、class切换、style修改等均可），只要视觉效果正确即可
